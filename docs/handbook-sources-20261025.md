# Handbook sources and scope

Checked on **2026-10-25**. The handbook is an original bilingual explanation of this repository's website, configuration and contribution contracts. It has three reading paths: first tasks, team use and developer reference. It does not report a new native App feature or a completed real-account task.

## Official platform references

These sources describe **Grok Bot**, not a list of implemented OpenBot capabilities:

- [Marketplace](https://x.ai/bot/marketplace) and [a public Bot detail](https://x.ai/bot/marketplace/bots/dr-eggbot-v2): discover a role, inspect its author and use the platform's import action.
- [Bots](https://docs.x.ai/grok-bot/bots) and [templates](https://x.ai/bot/guides/templates-for-grok-bot): a shared configuration does not transfer an author's computer, sign-ins or conversation history.
- [Skills, routines and automations](https://docs.x.ai/grok-bot/skills-routines-and-automations): task methods and scheduling are different; a platform Test action can perform real work.
- [Computer and apps](https://docs.x.ai/grok-bot/computer-and-apps) and [approvals, security and privacy](https://docs.x.ai/grok-bot/approvals-security-and-privacy): account access and approval controls belong to the actual host. Separate views do not establish security isolation.
- [Files and results](https://docs.x.ai/grok-bot/files-and-results) and [troubleshooting](https://docs.x.ai/grok-bot/troubleshooting): inspect deliverables and diagnose the failing layer before recovery actions.

Menus, account availability and hosted runtime behavior can change. The handbook does not advertise Grok's cloud computers, Connect apps, Auto Review, Teach a task or Routine controls as OpenBot features. No paid account or live account workflow was used for this content review.

## Project authority and generation

For Awesome Bot behavior, the authority is the current code plus [INTEGRATION.md](../INTEGRATION.md), [Agent integration](agent-integration.md), [market aggregation](market-aggregation.md), [contribution instructions](../CONTRIBUTING.md) and [publication process](publishing.md). The five scenario bodies are generated directly from the existing Chinese and English scenario records, including their actual Bot order, prompts, handoffs and download paths. Catalogue counts are computed at build time.

The website downloads configuration files and provides context for Agents. Host import, model setup, account access and execution are separate actions. Instructions do not grant tool access; an empty host library may assign its first imported Bot the primary role under that host's rules. Source links are not adapted configurations. Data-format and export tests do not certify each role's real-world results.

Handbook HTML is static and remains readable without JavaScript. Search uses a local-language index; chapter links, Markdown editions and source references stay available if search fails. Published template and registry bytes are preserved by this content-only release.
