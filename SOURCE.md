# Sources and authorship

The initial directory references the publicly available Grok Bot Marketplace and use-case catalogue, checked on 2026-10-20. `sources/grok-inventory.json` records public URLs, names, original authors, categories, dates, detail-page hashes and local mappings.

The initial 148 OpenBot personas, workflow instructions, skills and onboarding examples were independently authored. The 2026-10-24 expansion adds 223 attributed third-party roles whose original English instruction bodies are redistributed under CC0-1.0 or MIT. Each adaptation retains fixed-revision source links, file hashes, applicable copyright and license notices, and an explicit OpenBot host contract. See [market aggregation](docs/market-aggregation.md), [the source inventory](sources/bot-markets-20261024.md) and [third-party notices](THIRD_PARTY_NOTICES.md). No private memory, credentials, account connections or execution environments are redistributed. Neither a reference nor an adaptation implies identical behavior or original-author endorsement.

The 90 original role adaptations and 56 original task workflows are separate collections. Community originals need not map to Grok. An upstream “From Grok Bot Team” tag is a source fact, not a verification badge for this project's implementation.

The MIT OpenBot market implementation is included as a fixed snapshot under `engine/`. Its provenance records per-file SHA-256 hashes and original module paths. Existing schema, integrity, source-trust and materialization behavior were retained. This snapshot is not represented as a nonexistent published Git commit.

Awesome DSH Plugin and DSH Market inform organization and discovery. Their plugin counts and runtime formats are not substituted for Bot semantics. This catalogue does not execute DSH plugins.

Build validation proves document shape, source mappings, integrity and export behavior. It does not prove a model has performed every declared role, that a third-party account is connected, or that a task is appropriate in a user's environment.
